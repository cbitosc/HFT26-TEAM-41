## Single number

Implement `single_number` so that it returns the expected result for every input. The examples below show the exact input and output format; the hidden cases use more inputs of the same shape, including edge cases.

Topics: arrays, bit manipulation.

## Your function

```python
def single_number(nums: list[int]) -> int
```

## Examples

**Example 1.** `single_number(nums = [1])` returns `1`.

**Example 2.** `single_number(nums = [-1, -1, -2])` returns `-2`.
