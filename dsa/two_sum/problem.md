## Two sum

Implement `two_sum` so that it returns the expected result for every input. The examples below show the exact input and output format; the hidden cases use more inputs of the same shape, including edge cases.

Topics: arrays, hashing.

## Your function

Write `two_sum` in `solution.py`.

```python
def two_sum(nums: list[int], target: int) -> list[int]
```

## Examples

**Example 1.** `two_sum(nums = [3, 3], target = 6)` returns `[0, 1]`.

**Example 2.** `two_sum(nums = [1, 5, 7, 9], target = 10)` returns `[0, 3]`.

The returned list may be in any order.
