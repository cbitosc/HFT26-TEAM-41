## Three sum

Implement `three_sum` so that it returns the expected result for every input. The examples below show the exact input and output format; the hidden cases use more inputs of the same shape, including edge cases.

Topics: arrays, sorting, two pointers.

## Your function

Write `three_sum` in `solution.py`.

```python
def three_sum(nums: list[int]) -> list[list[int]]
```

## Examples

**Example 1.** `three_sum(nums = [0, 0, 0])` returns `[[0, 0, 0]]`.

**Example 2.** `three_sum(nums = [1, 2, -2, -1])` returns `[]`.
