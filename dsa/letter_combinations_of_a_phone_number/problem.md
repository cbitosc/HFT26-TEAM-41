## Letter combinations

Implement `letter_combinations` so that it returns the expected result for every input. The examples below show the exact input and output format; the hidden cases use more inputs of the same shape, including edge cases.

Topics: backtracking, hashing, strings.

## Your function

Write `letter_combinations` in `solution.py`.

```python
def letter_combinations(digits: str) -> list[str]
```

## Examples

**Example 1.** `letter_combinations(digits = "2")` returns `["a", "b", "c"]`.

**Example 2.** `letter_combinations(digits = "3")` returns `["d", "e", "f"]`.

The returned list may be in any order.
