## Combination sum

Implement `combination_sum` so that it returns the expected result for every input. The examples below show the exact input and output format; the hidden cases use more inputs of the same shape, including edge cases.

Topics: arrays, backtracking.

## Your function

Write `combination_sum` in `solution.py`.

```python
def combination_sum(candidates: list[int], target: int) -> list[list[int]]
```

## Examples

**Example 1.** `combination_sum(candidates = [7, 14], target = 30)` returns `[]`.

**Example 2.** `combination_sum(candidates = [1], target = 1)` returns `[[1]]`.

The returned list may be in any order.
