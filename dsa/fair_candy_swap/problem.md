## Fair candy swap

Topics: arrays, binary search, hashing, sorting.

## Your function

Write `fair_candy_swap` in `solution.py`.

```python
def fair_candy_swap(aliceSizes: list[int], bobSizes: list[int]) -> list[int]
```

## Examples

**Example 1.** `fair_candy_swap(aliceSizes = [1, 1], bobSizes = [2, 2])` returns `[1, 2]`.

**Example 2.** `fair_candy_swap(aliceSizes = [5, 4, 3], bobSizes = [7, 8, 9])` returns `[3, 9]`.
